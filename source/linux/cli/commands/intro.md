# コマンド一覧

知ったコマンドや使ったコマンドについて理解を深めるために作った。

| 記事 | 概要 |
| --- | --- |
| [grep](grep.md) | ファイル内や標準入力から、特定の文字列や正規表現に一致する行を抽出・検索する |
| [ip](ip.md) | IPアドレスの確認・設定、ルーティングテーブルやネットワークインターフェースの管理を行う（`ifconfig` の後継） |
| [env](env.md) | 現在設定されている環境変数を一覧表示する、または一時的に環境変数を変更してコマンドを実行する |
| [journalctl](journalctl.md) | systemd が収集したシステムログやサービス起動ログの閲覧・フィルタリング（時系列・重要度別）を行う |
| [lsusb](lsusb.md) | システムに接続されている USB デバイスの一覧や詳細情報（ベンダーID、製品名など）を確認する |
| [nc](nc.md) | TCP/UDP パケットの送受信、特定ポートへの接続疎通確認、簡易チャットやファイル転送を行う（別名: netcat） |
| [ss](ss.md) | 開いているポート、通信中のソケット、待ち受け（LISTEN）状態のプロセス情報を高速に確認する（`netstat` の後継） |
| [systemctl](systemctl.md) | OSサービス（デーモン）の起動・停止・再起動、ステータス確認や自動起動の設定を管理する |
| [tcpdump](tcpdump.md) | ネットワークを流れるパケットをリアルタイムにキャプチャし、中身や通信の流れを解析・ダンプする |
| [ufw](ufw.md) | ファイアウォールの通信制御（ポート開放・遮断）をシンプルかつ直感的に設定・管理する（iptables の簡易ラッパー） |
