# html書き方&&記法まとめ

## パーツの役割

| 記法 | 役割 |
| --- | --- |
| &lt;!DOCTYPE html&gt; | この文章はHTML5規格で書かれていることを宣言するためのもの |
| &lt;html lang="ja"&gt; | 文章全体を囲む**最上位要素**""ja""でページの主言語が日本語であると示すことができる |
| &lt;head&gt; | ブラウザの画面のは直接表示されないメタデータを記述するためのもの(以下三つはこの中に記載する) |
| &lt;meta charset="UTF-8"&gt; | 文字コードを指定する |
| &lt;meta name="viewport" content="width=device-width, initial-scale=1.0"&gt; | 画面幅に応じたレスポンシブ設定を行うための必須設定 |
| &lt;title&gt; | ブラウザのタブや検索結果に表示されるページタイトル |
| &lt;body&gt; | 実際にブラウザの画面上に表示されるコンテンツ（見出し、文章、画像、リンクなど）をすべて記述するエリアです |

## HTMLの基本構文ルール

### 1. 開始タグと終了タグ
基本的に、開始タグ &lt;タグ名&gt; と終了タグ &lt;/タグ名&gt;（スラッシュが必要）でテキストを囲みます。
例: &lt;p&gt;これは段落です。&lt;/p&gt;

### 2. 属性（Attributes）
タグに機能や設定を追加する場合、開始タグの中に 属性名="値" の形式で半角スペースを空けて記述します。
例: &lt;!-- href属性でリンク先を指定する --&gt;&lt;a href="https://example.com"&gt;ここをクリック&lt;/a&gt;

### 3. 空要素（終了タグがないタグ）
テキストを囲む必要がない単体で完結する要素には、終了タグがありません。
- &lt;meta&gt;: 設定情報
- &lt;img&gt;: 画像の埋め込み（src や alt 属性を伴う）
- &lt;br&gt;: 改行
- &lt;input&gt;: フォームの入力欄
例: &lt;img src="logo.png" alt="サイトのロゴ"&gt;

### 4. 入れ子（ネスト）の順序
タグの中に別のタグを入れる場合、開いた順の逆（内側のタグから順）で閉じる必要があります。順序が交差すると文法エラーになります。
- 正しい例: &lt;p&gt;これは&lt;strong&gt;重要&lt;/strong&gt;です。&lt;/p&gt;
- 誤った例: &lt;p&gt;これは&lt;strong&gt;重要です。&lt;/p&gt;&lt;/strong&gt;（交差している）

### 5. コメントアウト
ブラウザに表示させず、ソースコード内にメモを残したい場合は &lt;!-- と --&gt; で囲みます。
例: &lt;!-- ここからメインコンテンツ --&gt;&lt;div&gt;...&lt;/div&gt;

## まず覚えるべき必須タグ

| 記法 | 役割 |
| --- | --- |
| &lt;h1&gt; 〜 &lt;h6&gt; | **見出し**：重要度順に指定（1ページに &lt;h1&gt; は原則1つ） |
| &lt;p&gt; | **段落**：文章のまとまりを表す |
| &lt;a href="URL"&gt;表示文字&lt;/a&gt; | **リンク**：別ページや指定URLへの遷移先を設定する |
| &lt;img src="画像パス" alt="画像の説明"&gt; | **画像**：画像を埋め込む（alt は代替テキスト） |
| &lt;ul&gt; + &lt;li&gt; | **箇条書きリスト**：順不同のリスト（&lt;ul&gt; 内に &lt;li&gt; を配置） |
| &lt;ol&gt; + &lt;li&gt; | **番号付きリスト**：順序のあるリスト（&lt;ol&gt; 内に &lt;li&gt; を配置） |
| &lt;div&gt; | **ブロックグループ化**：レイアウト用に要素をまとめてブロック化する |
| &lt;span&gt; | **インライングループ化**：文章内の一部分（特定テキスト）を囲んで装飾・識別する |

他のタグは適宜追加していく予定

## 骨組み(参考)

```html
<!DOCTYPE html>
<html lang="ja">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>ページのタイトル</title>
</head>
<body>
  <h1>大見出し</h1>
  <p>ここに本文が入ります。</p>
</body>
</html>
```
