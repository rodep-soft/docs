## html


| 記法 | 役割 |
| --- | --- |
| <!DOCTYPE html> |


閉じるときは例外な&lt;タグ名&gt;を用いる

## 骨組み(参考)

```html
<!DOCTYPE html>
<html lang="ja">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>ページのタイトル</title>
</head>
<body>
  <h1>大見出し</h1>
  <p>ここに本文が入ります。</p>
</body>
</html>
```
