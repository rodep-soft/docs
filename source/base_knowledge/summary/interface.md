**入出力インタフェース**とは、コンピュータと周辺機器の間でデータをやり取りするための接続規格・仕組みである。

**USB:Universal Serial Bus**は、**1ビットずつデータを転送するシリアルインタフェース**であり、コンピュータと周辺機器を接続してデータ通信や電力供給を行うための規格。

**USBハブ**は、1つのUSBポートを複数のUSBポートに分岐し、複数のUSB機器を接続できるようにする機器。USBでは**最大127台のデバイス**を接続できる。

# USBの規格

| 規格          | モード                                | 最大転送速度 |
| ------------- | ------------------------------------- | -----------: |
| USB 1.0 / 1.1 | ロースピード（Low-Speed）             |     1.5 Mbps |
| USB 1.0 / 1.1 | フルスピード（Full-Speed）            |      12 Mbps |
| USB 2.0       | ハイスピード（High-Speed）            |     480 Mbps |
| USB 3.0       | スーパースピード（SuperSpeed）        |       5 Gbps |
| USB 3.1       | スーパースピードプラス（SuperSpeed+） |      10 Gbps |
| USB 3.2       | スーパースピードプラス（SuperSpeed+） |      20 Gbps |
| USB4          | USB4 20Gbps / 40Gbps / 80Gbps         |  最大80 Gbps |

## USBコネクタの形状

- USB Type-A：パソコンなどに広く使われてきた長方形のコネクタ
- USB Type-B：プリンタなどの周辺機器で使用されることが多いコネクタ
- USB Type-C：小型で上下の向きを気にせず接続できるコネクタ
- Mini-USB：小型機器などで使用されていた小型コネクタ
- Micro-USB：スマートフォンなどで広く使用されていた小型コネクタ

### USBポートの色（補足）

USBポートの色は規格や機能を示す目安として使われるが、**メーカーによって異なるため、色だけで規格を判断することはできない**。

- 白・黒：USB 1.x / USB 2.0などで使用されることが多い
- 青：USB 3.x系で使用されることが多い
- 水色：USB 3.1 / USB 3.2 Gen 2などで使用される場合がある
- 赤・黄色：電源供給機能が強化されたポートなどで使用される場合がある

**ホットプラグ**とは、**コンピュータの電源を切らずにUSB機器などを接続・取り外しできる機能**である。

**バスパワー**とは、**USBなどの接続先から供給される電力によって周辺機器を動作させる方式**である。外部電源を必要としないため、USBメモリやマウスなどの小型機器で利用される。

**HDMI:High-Definition Multimedia Interface**は、**映像・音声・制御信号をデジタル伝送できるインタフェース**で、テレビやディスプレイ、ゲーム機などで利用される。

**Bluetooth**は、**2.4GHz帯の電波**を利用して、近距離の機器同士を無線接続する通信規格である。マウス、キーボード、イヤホンなどに利用される。

**BLE:Bluetooth Low Energy**は、Bluetoothの規格の一つで、**2.4GHz帯の電波を利用し、低消費電力で近距離通信を行うことに適している**。センサーやウェアラブル機器などで利用される。

**Zigbee**は、**2.4GHz帯などの電波を利用する短距離無線通信規格**で、低消費電力・低速通信を特徴とする。複数の機器を中継して通信するメッシュネットワークを構築でき、センサーやスマートホーム機器などに利用される。

**PAN:Personal Area Network**は、**個人の周囲にある機器を接続する小規模なネットワーク**である。Bluetooth、Bluetooth Low Energy（BLE）、Zigbeeなどの短距離無線通信を利用して構築でき、スマートフォンとイヤホン、センサーなどの接続に利用される。
