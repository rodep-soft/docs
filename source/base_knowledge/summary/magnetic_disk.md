| 項目             | 内容                                                         |
| ---------------- | ------------------------------------------------------------ |
| **磁気ディスク** | **磁性体を塗布した円盤に、データを磁気的に記録する記憶媒体** |
| **代表例**       | HDD（ハードディスクドライブ）                                |
| **特徴**         | 円盤を回転させ、磁気ヘッドによってデータの読み書きを行う     |
| **用途**         | OS、アプリケーション、文書、画像などのデータを長期間保存する |

# 磁気ディスクの構造

| 用語         | 構造                                                       | 内容                                |
| ------------ | ---------------------------------------------------------- | ----------------------------------- |
| **セクタ**   | トラックを分割した領域                                     | **データを記録する基本単位**        |
| **トラック** | セクタが円周方向に並んだ領域                               | **同心円状の記録領域**              |
| **シリンダ** | 複数のディスク面にある同じ半径位置のトラックをまとめたもの | **複数のトラックをまとめた概念**    |
| **プラッタ** | データを記録する円盤                                       | HDD内部に複数枚搭載されることがある |
| **ヘッド**   | ディスク表面に対応する読み書き装置                         | データの読み書きを行う              |

## 構造の関係

**セクタ → トラック → シリンダ**

- **セクタ**：トラックを分割したもの
- **トラック**：セクタが円周方向に並んだもの
- **シリンダ**：複数のディスク面にある同じ位置のトラックをまとめたもの(物理的に存在するものではなく論理的な概念)

| 方式                 | 特徴                                                            |
| -------------------- | --------------------------------------------------------------- |
| **固定長セクタ方式** | 1セクタあたりの容量を一定にする方式。現在の磁気ディスクで一般的 |
| **可変長セクタ方式** | セクタごとに記録するデータ量を変えられる方式                    |

### 現在のセクタ方式

- 現在のHDDでは、基本的に**固定長セクタ方式**が使われる
- データはセクタ単位で管理され、**1つのセクタに収まらないデータは次のセクタへ移る**
- ファイルの大きさがセクタ容量の整数倍でない場合、最後のセクタには**使用されない領域**が生じる

| 用語                           | 内容                                                                                               |
| ------------------------------ | -------------------------------------------------------------------------------------------------- |
| **アクセス時間**               | データを要求してから、目的のデータを読み書きできるまでにかかる時間                                 |
| **シーク時間（位置決め時間）** | 磁気ヘッドを目的の**トラックまで移動させる時間**                                                   |
| **回転待ち時間（サーチ時間）** | 目的のトラックにヘッドを移動した後、目的の**セクタが磁気ヘッドの位置まで回転してくるのを待つ時間** |
| **データ転送時間**             | **目的のデータが磁気ヘッドを通り過ぎ、読み書きが完了するまでに要する時間**                         |

### アクセス時間の関係

**アクセス時間 ≒ シーク時間（位置決め時間）＋ 回転待ち時間 ＋ データ転送時間**

> ※上記はアクセス時間を構成する**概念的な時間**。実際の装置では、コントローラなどによる処理時間も含まれる。

| 項目                 | 内容                                           |
| -------------------- | ---------------------------------------------- |
| **平均回転待ち時間** | 目的のセクタが到達するまでの平均待ち時間       |
| **求め方**           | **1回転にかかる時間 ÷ 2**                      |
| **例：7,200rpm**     | 1回転 ≒ 8.33ms → 平均回転待ち時間 ≒ **4.17ms** |

| 用語                         | 内容                                                                                             |
| ---------------------------- | ------------------------------------------------------------------------------------------------ |
| **フラグメンテーション**     | ファイルや空き領域がディスク上で**断片化**する現象                                               |
| **内部フラグメンテーション** | 割り当てられた領域の中に、実際には使用されない**無駄な領域**が発生する                           |
| **外部フラグメンテーション** | 空き領域がディスク上に**細かく分散**し、連続した大きな空き領域を確保しにくくなる                 |
| **デフラグ**                 | (フラグメンテーションを解消できる)ファイルの断片化を整理し、データを連続した領域に再配置する処理 |

### HDDでのフラグメンテーション

**断片化 → シーク回数増加 → シーク時間増加 → HDDの読み書き性能低下**

HDDでは、デフラグによってファイルを整理することで性能を改善できる場合がある。

> ※SSDではHDDのような磁気ヘッドの移動がないため、フラグメンテーションによるアクセス性能への影響はHDDほど大きくない。
