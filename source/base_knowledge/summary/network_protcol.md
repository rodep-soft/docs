# OSI参照モデルとTCP/IP階層モデルの体系的整理

## 1. OSI参照モデル（Open Systems Interconnection）の基本

| 項目              | 内容                                                                                                                    |
| ----------------- | ----------------------------------------------------------------------------------------------------------------------- |
| **OSI参照モデル** | **ISO（国際標準化機構）**が策定した、異なるベンダー間の機器が通信できるようにするための**ネットワーク設計の基本モデル** |
| **基本構造**      | ネットワークの通信機能を**7つの階層（レイヤー）**に分割し、各層ごとに役割を独立させている                               |
| **目的**          | 規格の標準化による**相互接続性の確保**と、機能分割による開発・トラブルシューティングの効率化                            |

---

## 2. OSI参照モデルの7つの階層（レイヤー構造）

| 階層      | 層名                     | 役割・内容                                                                            | データの扱い（PDU）      |
| --------- | ------------------------ | ------------------------------------------------------------------------------------- | ------------------------ |
| **第7層** | **アプリケーション層**   | 利用者が扱う**アプリケーション間の通信サービス**を提供する                            | **データ（メッセージ）** |
| **第6層** | **プレゼンテーション層** | データの**表現形式（文字コード、暗号化、圧縮など）**を共通形式に変換・統一する        | **データ**               |
| **第5層** | **セッション層**         | アプリケーション間の**通信の開始（確立）、維持、終了（切断）**の対話を管理する        | **データ**               |
| **第4層** | **トランスポート層**     | データの**到達保証・信頼性確保**、または高速転送を制御する                            | **セグメント**           |
| **第3層** | **ネットワーク層**       | **IPアドレス**に基づき、異なるネットワーク間の**経路選択（ルーティング）**を行う      | **パケット**             |
| **第2層** | **データリンク層**       | **MACアドレス**に基づき、同一ネットワーク内の**直接隣接する機器間での通信**を制御する | **フレーム**             |
| **第1層** | **物理層**               | データを電気信号、光信号、電波などの**物理的なビット列（0と1）**に変換して送受信する  | **ビット**               |

### ネットワーク機器とデータの送受信プロセス（カプセル化）

| 装置・用語                 | 対応レイヤー / 処理内容           | 内容                                                                              |
| -------------------------- | --------------------------------- | --------------------------------------------------------------------------------- |
| **ゲートウェイ**           | **第4層〜第7層**                  | プロトコル体系が異なるネットワーク同士を変換して接続する装置                      |
| **ルータ（L3スイッチ）**   | **第3層（ネットワーク層）**       | **IPアドレス**を参照し、最適な経路へパケットを中継（ルーティング）する装置        |
| **ブリッジ（L2スイッチ）** | **第2層（データリンク層）**       | **MACアドレス**を参照し、宛先のポートにのみフレームを中継（スイッチング）する装置 |
| **リピータ（ハブ）**       | **第1層（物理層）**               | 減衰した**電気信号を増幅・整形**し、伝送距離を延ばす装置                          |
| **カプセル化**             | **送信時の処理**（上位層→下位層） | データに各層の**制御情報（ヘッダ等）を付加**していく処理                          |
| **非カプセル化**           | **受信時の処理**（下位層→上位層） | 該当する層の**ヘッダを読み取って取り外す**処理                                    |

## 3. TCP/IP階層モデルと通信プロトコル

| 用語                       | 内容                                                                                                                                                    |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **プロトコル**             | ネットワーク上でコンピュータ同士が通信を行うための**約束事（通信規約・手順）**                                                                          |
| **デファクトスタンダード** | 公的な標準化機関が定めたものではないが、市場での競争の結果、広く普及して**事実上の世界標準**となった規格                                                |
| **TCP/IP**                 | 現在のインターネットで標準的に利用されている**デファクトスタンダード**の通信プロトコル群。OSIモデルの7階層に対し、実用性を重視した**4階層**で構成される |

---

## 4. TCP/IP 各階層の主要プロトコル詳細

### アプリケーション層のプロトコル

OSI参照モデルの第5〜7層（セッション・プレゼンテーション・アプリケーション層）に相当。

**【最も重要なプロトコル】**
| プロトコル | 内容 |
| --- | --- |
| **HTTP** | WebサーバとWebブラウザ間で、**HTMLなどのWebコンテンツを送受信**するためのプロトコル |
| **NTP** | ネットワーク経由で機器の**システム時計を正しい時刻に同期**させるためのプロトコル |
| **SMTP** | 電子メールを**送信・転送**するためのプロトコル |
| **POP3** | メールサーバから電子メールを**受信（端末にダウンロード）**するためのプロトコル |

**【重要なプロトコル】**
| プロトコル | 内容 |
| --- | --- |
| **FTP** | ネットワーク上で**ファイルを転送**するためのプロトコル |
| **TELNET** | ネットワーク経由で他のコンピュータに遠隔ログインし、**リモート操作**を行うためのプロトコル（通信は暗号化されない） |
| **SNMP** | ルータやスイッチなどの**ネットワーク機器を監視・管理**し、障害情報を収集するためのプロトコル |
| **IMAP4** | サーバ上でメールを管理し、**メールをサーバに置いたまま閲覧・操作**するための受信プロトコル |

### トランスポート層のプロトコル

OSI参照モデルの第4層（トランスポート層）に相当。通信の信頼性や速度を制御する。

> **💡 TCPとUDPの【本質的な違い】**：送信したデータが相手に無事届いたか（遅れていないか・欠損していないか）を確認するかどうか」にあります。

| プロトコル | 特徴                             | 内容                                                                                                         |
| ---------- | -------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| **TCP**    | **到達確認をする（信頼性重視）** | コネクションを確立し、**データが届いたかの確認（ACK）や再送処理**を行う確実な通信方式。Webやメール等で使用   |
| **UDP**    | **到達確認をしない（速度重視）** | 到達確認を行わず、**データを送りっぱなし**にするため**低遅延・高速な転送**が可能。音声通話や動画配信等で使用 |

### インターネット層のプロトコル

OSI参照モデルの第3層（ネットワーク層）に相当。経路選択を担う。

| 用語・プロトコル | 内容                                                                                                          |
| ---------------- | ------------------------------------------------------------------------------------------------------------- |
| **IP**           | **IPアドレス**を用いて、パケットを最終的な宛先まで届けるためのプロトコル                                      |
| **ICMP**         | IP通信における**エラー通知や制御メッセージ**を転送するためのプロトコル（例：**pingコマンド**）                |
| **MACアドレス**  | ネットワーク機器に割り当てられた**固有の物理アドレス**。同一ネットワーク内の機器特定に使用                    |
| **ARP**          | 宛先の**IPアドレス（論理アドレス）から、対応するMACアドレス（物理アドレス）を問い合わせて解決**するプロトコル |

### ネットワークインタフェース層のプロトコル

OSI参照モデルの第1〜2層（物理層・データリンク層）に相当。隣接ノード間の通信を担う。

| プロトコル | 内容                                                                                                                  |
| ---------- | --------------------------------------------------------------------------------------------------------------------- |
| **PPP**    | 1対1（Point-to-Point）で直接接続された機器間で通信を行うためのプロトコル。**ユーザ認証**機能を備える                  |
| **PPPoE**  | **PPPの機能をイーサネット（Ethernet）上で利用**できるようにしたプロトコル。光回線等のプロバイダ接続認証で広く使われる |
