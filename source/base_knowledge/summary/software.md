# コンピュータ構成

| 分類                 | 説明                                                                     |
| -------------------- | ------------------------------------------------------------------------ |
| **ハードウェア**     | コンピュータを構成する物理的な機器。                                     |
| **基本ソフトウェア** | コンピュータ全体を管理・制御するソフトウェア。                           |
| **ミドルウェア**     | 基本ソフトウェアと応用ソフトウェアの間で共通機能を提供するソフトウェア。 |
| **応用ソフトウェア** | 利用者の目的に応じた処理を行うソフトウェア。                             |

## OS

**OS（Operating System）**：コンピュータを管理・制御する基本機能を提供するソフトウェア。

### OSの主な管理機能

| 管理機能         | 説明                                                 |
| ---------------- | ---------------------------------------------------- |
| **ジョブ管理**   | コンピュータに依頼する仕事のスケジュールの管理       |
| **タスク管理**   | CPUを効率よく利用するために使う                      |
| **記憶管理**     | 主記憶装置（メインメモリ）の領域を効率的に管理する。 |
| **ファイル管理** | ファイルやディレクトリを管理する。                   |

**ミドルウェア**：多くのアプリケーションが必要とする共通の基本機能や統一的なインタフェースを提供するソフトウェア。

**DBMS**：データベースを管理し、データの検索・追加・更新・削除などを行うソフトウェア。

| 用語                                         | 説明                                                                                         |
| -------------------------------------------- | -------------------------------------------------------------------------------------------- |
| **API（Application Programming Interface）** | ある機能を公開しているソフトウェアと、それを利用するソフトウェアとの間に働くインタフェース。 |
| **プラグアンドプレイ**                       | コンピュータに接続した周辺機器をOSが自動的に認識し、必要な設定を行う仕組み。                 |
| **デバイスドライバ**                         | プリンタやキーボードなどの周辺機器を制御するためのソフトウェア。                             |
