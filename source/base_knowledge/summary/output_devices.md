**出力装置**とは、コンピュータで処理した情報を人間が認識できる形で外部へ出力するための装置であり、ディスプレイ、プリンタ、スピーカーなどがある。

# ディスプレイ

| 種類                                 | 特徴                                                                                                     |
| ------------------------------------ | -------------------------------------------------------------------------------------------------------- |
| 液晶ディスプレイ（LCD）              | 液晶分子に電圧を加えることで分子の向きを変化させ、光の透過量を調節して表示する。バックライトを必要とする |
| 有機エレクトロルミネッセンス（OLED） | 有機化合物に電圧を加えることで自ら発光させて表示する。バックライトが不要で、高コントラスト・薄型化が可能 |
| 発光ダイオード（LED）ディスプレイ    | 発光ダイオードを利用して光を発する表示方式。高輝度で大型表示などに利用される                             |
| ブラウン管（CRT）ディスプレイ        | 電子ビームを蛍光面に当てて発光させる方式。大型・重量があるため現在はほぼ使われない                       |

**解像度**とは、画面を構成する画素（ピクセル）の数であり、「1920×1080」のように横×縦の画素数で表す。一般に解像度が高いほど、より細かく鮮明に表示できる。

**ビデオメモリ**（Video Random Access Memory）は、画像や映像を表示するためのデータを一時的に保存するメモリである。

一般に、1画素あたりnビットの情報を扱う場合、1画素につき**2ⁿ通り**の色や明るさなどを表現できる。例えば、8ビットなら**2⁸＝256通り**を表現できる。

また、VRAMの容量が大きいほど、高解像度・高色深度の画像を扱いやすくなる。

## 色の表現

| 装置         | 色の表現                                                                             |
| ------------ | ------------------------------------------------------------------------------------ |
| ディスプレイ | RGB（Red・Green・Blue）の光の三原色を組み合わせて色を表現する                        |
| プリンタ     | CMYK（Cyan・Magenta・Yellow・Key plate）の色材の三原色＋黒を組み合わせて色を表現する |

## プリンタの種類

| 種類                     | 特徴                                                               |
| ------------------------ | ------------------------------------------------------------------ |
| インクジェットプリンタ   | インクを用紙に吹き付けて印刷する。カラー印刷に適する               |
| レーザープリンタ         | トナーとレーザーを利用して印刷する。高速で大量印刷に適する         |
| ドットインパクトプリンタ | 印字ヘッドでインクリボンを叩いて印刷する。複写伝票などに利用される |
| 感熱式プリンタ           | 熱を利用して専用紙に印刷する。レシートなどに利用される             |

**PPM:Pages Per Minute**は、プリンタが**1分間に印刷できるページ数**を表す印刷速度の単位で、値が大きいほど短時間に多くのページを印刷できる。

**DPI:Dots Per Inch**は、**1インチあたりに印刷できるドットの数**を表す印刷解像度の単位である。DPIの値が大きいほど、1インチの中により多くのドットを配置でき、一般に細かく鮮明な印刷ができる。

**3Dプリンタ**は、樹脂などの材料を層状に積み重ねて、立体物を造形する装置である。設計データをもとに複雑な形状の部品や模型などを製作できる。
