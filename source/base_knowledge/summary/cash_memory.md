| 項目                 | 内容                                                                                      |
| -------------------- | ----------------------------------------------------------------------------------------- |
| **キャッシュメモリ** | CPUと**主記憶（RAM）**の間に置き、CPUがよく使うデータや命令を一時的に保存する高速なメモリ |
| **目的**             | CPUと主記憶（RAM）の速度差を埋め、CPUの待ち時間を減らす                                   |
| **使用されるメモリ** | 主に**SRAM**                                                                              |

<br>

| 種類                               | 特徴                        | 速度         | 容量         |
| ---------------------------------- | --------------------------- | ------------ | ------------ |
| **一次キャッシュ（L1キャッシュ）** | CPUコアに最も近い           | **最も高速** | **小さい**   |
| **二次キャッシュ（L2キャッシュ）** | L1よりCPUコアから離れている | L1より遅い   | L1より大きい |

### 関係

**CPU → L1キャッシュ → L2キャッシュ → 主記憶（RAM）**

CPUは必要なデータを、まずL1、次にL2、それでもなければ主記憶（RAM）から探す。

# キャッシュメモリ関連

| 用語                   | 特徴                                                                                    | 動作                                                                                                     |
| ---------------------- | --------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| **ライトスルー方式**   | キャッシュと主記憶（RAM）を**同時に更新**する方式                                       | CPUがデータを書き込む → **キャッシュと主記憶（RAM）の両方に書き込む**                                    |
| **ライトバック方式**   | キャッシュのデータを更新し、**主記憶（RAM）への書き込みを後回し**にする方式             | CPUがデータを書き込む → **キャッシュだけ更新** → キャッシュから追い出すときなどに主記憶（RAM）へ書き込む |
| **メモリインタリーブ** | 主記憶（RAM）を複数の**バンク**に分け、並列的にアクセスすることで高速化する方式         | 連続するデータを複数のバンクに分散して格納 → **複数バンクへ並列・交互にアクセス**                        |
| **ECCメモリ**          | データに**誤り訂正符号（ECC）**を付加し、メモリ上で発生した誤りを検出・訂正できるメモリ | データとECCを一緒に保存 → 読み出し時に誤りを検出 → **訂正可能な誤りを自動訂正**                          |

|                        | ライトスルー                | ライトバック                          |
| ---------------------- | --------------------------- | ------------------------------------- |
| CPUが書き込み          | キャッシュ＋主記憶（RAM）   | **キャッシュのみ**                    |
| 主記憶（RAM）の更新    | **すぐに行う**              | **後で行う**                          |
| 主記憶への書き込み回数 | 多い                        | **少ない**                            |
| 処理速度               | 比較的遅い                  | **高速**                              |
| データの整合性管理     | 比較的簡単                  | 複雑                                  |
| ポイント               | **書いたらすぐRAMにも反映** | **キャッシュで更新して後でRAMに反映** |

## ECCメモリのポイント

- **1ビットの誤り**など、訂正可能な誤りを自動的に訂正できる
- **2ビット以上の誤り**などは、方式によって検出できるが訂正できない場合がある
- サーバーなど、**高い信頼性が求められるシステム**で利用される

ECCメモリでは、**2ビットの誤りを検出し、1ビットの誤りを訂正できるハミング符号**などの誤り訂正符号を利用する。

### 覚え方

- **ライトスルー** → 「書いたら**すぐRAMへ**」
- **ライトバック** → 「書いたら**いったんキャッシュへ**」
- **メモリインタリーブ** → 「RAMを**分割して並列アクセス**」
- **ECCメモリ** → 「**誤りを検出・訂正**できるRAM」
