**フラッシュメモリ**は、**電気的にデータを書き換えられる不揮発性メモリ**。電源を切ってもデータを保持でき、EEPROMを発展させたもの。大容量化しやすい。

- **具体例**：USBメモリ、SDカード、SSD
- **容量**：数GB～数TB程度など、用途によって幅広い
- **特徴**：機械的な駆動部分を持たないため、HDDより高速・静音・耐衝撃性に優れる
- **注意**：書き換え回数には上限があるため、ウェアレベリングなどで特定の領域への書き込みを分散させる

| 用語           | 略称                  | 特徴                                                                                                              |
| -------------- | --------------------- | ----------------------------------------------------------------------------------------------------------------- |
| **SSD**        | **Solid State Drive** | フラッシュメモリを使用した補助記憶装置。HDDのような磁気ディスクや磁気ヘッドを持たず、高速・静音・耐衝撃性に優れる |
| **光ディスク** | ―                     | **レーザー光を利用してデータを読み書きする記憶媒体**。CD、DVD、BDなどがある                                       |

# ウェアレベリング（Wear Leveling）

- フラッシュメモリの**書き換え回数を各記憶領域に分散**させる技術
- 特定の記憶領域だけが繰り返し書き換えられることを防ぐ
- フラッシュメモリの**寿命を延ばす**ことが目的

## SDカードの規格

| 規格     | 正式名称                             |          容量 | 特徴                           |
| -------- | ------------------------------------ | ------------: | ------------------------------ |
| **SD**   | **Secure Digital**                   |   **最大2GB** | SDカードの基本規格             |
| **SDHC** | **Secure Digital High Capacity**     | **4GB～32GB** | SD規格を大容量化したもの       |
| **SDXC** | **Secure Digital eXtended Capacity** | **64GB～2TB** | SDHCよりさらに大容量化した規格 |

### 容量の関係

**SD → SDHC → SDXC**

※SDXC対応機器では、SDHCやSDも基本的に使用できるが、**機器側の対応規格を確認する必要がある**。

## 光ディスクの記憶方式

| 記憶方式       | 略称・名称                                | 特徴                                                                         | 書き込み・消去                    | 具体例                      |
| -------------- | ----------------------------------------- | ---------------------------------------------------------------------------- | --------------------------------- | --------------------------- |
| **再生専用型** | **ROM（Read Only Memory）**               | 工場出荷時などにデータが記録され、**ユーザーによる書き込み・消去ができない** | 書き込み不可・消去不可            | **CD-ROM、DVD-ROM、BD-ROM** |
| **追記型**     | **R（Recordable）**                       | 一度だけデータを書き込める。書き込んだデータの**消去・上書きはできない**     | **1回だけ書き込み可能**・消去不可 | **CD-R、DVD-R、BD-R**       |
| **書換え型**   | **RW（ReWritable）／RE（RE-recordable）** | データを**消去して再び書き込める**                                           | **書き換え可能**                  | **CD-RW、DVD-RW、BD-RE**    |

## 光ディスクの代表例

| 種類    | 正式名称               | 代表的な容量                     | 使用例                                                 |
| ------- | ---------------------- | -------------------------------- | ------------------------------------------------------ |
| **CD**  | Compact Disc           | **約700MB**                      | 音楽CD、ソフトウェア、データ保存                       |
| **DVD** | Digital Versatile Disc | **約4.7GB（片面1層）**           | 映画・ドラマなどの映像作品、ゲームソフト、データ保存   |
| **BD**  | Blu-ray Disc           | **25GB（1層）・50GB（2層）など** | 高画質な映画・ドラマ、ゲームソフト、大容量データの保存 |
