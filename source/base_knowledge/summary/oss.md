**OSS（Open Source Software）**：ソースコードが公開され、無保証を原則に、一定の条件の下で利用・改変・再配布ができるソフトウェア。

# 具体例

- **Firefox**：Webブラウザ
- **Linux**：OSのカーネル
- **Thunderbird**：メールクライアント
- **Eclipse**：統合開発環境
- **Apache**：Webサーバソフトウェア
- **BIND**：Domain Name System（DNS）サーバソフトウェア
- **Postfix**：メール転送エージェント
- **MySQL**：データベース管理システム
- **PostgreSQL**：データベース管理システム

## OSI（Open Source Initiative）のオープンソースの10条件

| 条件                             | 内容                                                                                             |
| -------------------------------- | ------------------------------------------------------------------------------------------------ |
| **無償での再配布**               | ソフトウェアを販売・配布することを制限してはいけない。                                           |
| **ソースコード**                 | ソースコードを入手できるようにしなければならない。                                               |
| **派生ソフトウェア**             | ソフトウェアの改変や派生ソフトウェアの作成を認めなければならない。                               |
| **作者のソースコードの完全性**   | 改変されたソースコードを配布する場合、元のソースコードと区別できるようにすることを認めてもよい。 |
| **個人・グループへの差別禁止**   | 特定の個人やグループを利用から排除してはいけない。                                               |
| **利用分野への差別禁止**         | 商用・非商用など、特定の分野での利用を禁止してはいけない。                                       |
| **ライセンスの配布**             | ソフトウェアを再配布された人にも、元のライセンスと同じ権利が与えられなければならない。           |
| **特定製品への限定禁止**         | 特定の製品だけを対象としたライセンスにしてはいけない。                                           |
| **他のソフトウェアへの制限禁止** | OSSと一緒に配布される別のソフトウェアに、OSSのライセンスを強制してはいけない。                   |
| **技術的中立性**                 | 特定の技術やインタフェースを利用することを条件としてはいけない。                                 |

**OSSライセンス**：OSSを利用・改変・再配布するときに守るべき条件を定めたもの。

OSSだからといって「何をしても自由」というわけではなく、ライセンスごとに条件が異なる。

**GPL（GNU General Public License）**：利用・改変・再配布の自由を保証し、派生物を配布する場合にも同じ自由を維持することを求めるライセンス。

- **コピーレフト型**
- 改変したソフトウェアを配布する場合、原則として派生物もGPLの条件で提供する必要がある。
- ソースコードの提供など、ライセンスで定められた条件を守る必要がある。

**BSDライセンス**：利用・改変・再配布についての制約が比較的少ないOSSライセンス。

- **非コピーレフト型**
- 改変したソフトウェアをクローズドソースで配布することも可能。
- 著作権表示など、ライセンスで定められた条件を守る必要がある。

### GPLとBSDの違い

| 項目                           | GPL            | BSD              |
| ------------------------------ | -------------- | ---------------- |
| 種類                           | コピーレフト型 | 非コピーレフト型 |
| 改変                           | 可能           | 可能             |
| 再配布                         | 可能           | 可能             |
| 派生物へのライセンス継承       | **要求する**   | **要求しない**   |
| クローズドソースでの派生物配布 | 原則として不可 | **可能**         |
| 制約                           | 比較的多い     | 比較的少ない     |
