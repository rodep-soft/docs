**入力装置**とは、**コンピュータにデータや命令を入力するための装置**。

**ポインティングデバイス**とは、**画面上の位置を指定・操作するための入力装置**。マウス、タッチパッド、タッチパネルなどがある。

**タッチパネル**とは、**画面への接触位置を検出して入力を行う装置**。

# 静電容量方式

| 項目         | 内容                                                                       |
| ------------ | -------------------------------------------------------------------------- |
| **認識方式** | 画面に触れたときに生じる**静電容量の変化**を検出して、触れた位置を認識する |
| **特徴**     | 指などの導電性の物体が触れることで静電容量が変化する                       |
| **主な用途** | スマートフォン、タブレットなど                                             |

**バーコードリーダー**は、**バーコードに光を当てて反射光を読み取り、記録された情報をコンピュータに入力する装置**。商品の識別や在庫管理などに利用される。

| 種類          | 正式名称                    | 内容                                                                                | 主な用途                                   |
| ------------- | --------------------------- | ----------------------------------------------------------------------------------- | ------------------------------------------ |
| **JANコード** | **Japanese Article Number** | 商品に付けられた**1次元バーコード**。商品の識別番号を表す                           | 商品の販売管理、在庫管理など               |
| **QRコード**  | **Quick Response Code**     | 縦・横の2方向に情報を記録できる**2次元コード**。JANコードより多くの情報を格納できる | WebサイトのURL、決済情報、チケット情報など |

**POS（Point Of Sale）システム**とは、商品の販売時点で、**商品・価格・販売数量などの情報を収集・管理するシステム**。

バーコードリーダーなどで商品を読み取り、販売情報を記録することで、**売上管理や在庫管理、販売分析**などに利用できる。

**RFID:Radio Frequency Identification**とは、**電波を利用してICタグなどに記録された情報を非接触で読み取る技術**。

| 項目             | 内容                                                                                              |
| ---------------- | ------------------------------------------------------------------------------------------------- |
| **ICタグ**       | ICチップとアンテナを組み合わせたタグ。商品などに取り付けて情報を管理する                          |
| **読み取り方法** | 電波を利用して非接触で読み取る                                                                    |
| **特徴**         | バーコードのように1つずつ光学的に読み取る必要がなく、**複数のタグをまとめて読み取れる場合がある** |
| **用途**         | 商品管理、物流、入退室管理、交通系カードなど                                                      |

**NFC:Near Field Communication**とは、**数cm程度の近距離で機器同士を無線通信させる技術**。

| 項目             | 内容                                                     |
| ---------------- | -------------------------------------------------------- |
| **通信距離**     | 数cm程度の近距離                                         |
| **特徴**         | 機器を近づけるだけで通信できる                           |
| **用途**         | 非接触決済、交通系ICカード、スマートフォン同士の通信など |
| **RFIDとの関係** | **NFCはRFIDの技術を基盤とした近距離無線通信規格の一つ**  |

## 関係のイメージ

**バーコードリーダー → 光で読み取る**

**RFID → 電波でICタグを読み取る**

**NFC → 非常に近い距離で機器・タグ同士を通信する**
