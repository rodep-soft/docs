# ネットワーク・通信技術の基本構造

| 項目        | 内容                                                                                                              |
| ----------- | ----------------------------------------------------------------------------------------------------------------- |
| **有線LAN** | ケーブルを用いて機器を接続するLAN。現在は主に**イーサネット (Ethernet)**と呼ばれる規格が使われている              |
| **無線LAN** | 電波などを利用して機器を接続するLAN。接続方式には**インフラストラクチャモード**と**アドホックモード**がある       |
| **Wi-Fi**   | 無線LANの相互接続性を保証するブランド名。**WIFI-detect**は、端末が周囲の利用可能なWi-Fi電波（SSID）を検知する機能 |

## 無線LANの通信モード

**インフラストラクチャモード と アドホックモード**

- **インフラストラクチャモード**：端末が**アクセスポイント（基地局）**を経由して通信する、一般的なネットワーク構成
- **アドホックモード**：アクセスポイントを経由せず、**端末同士が直接通信**を行う構成

# アクセス制御方式

| 用語        | 意味                                 | 対象    | 内容                                                                                                           |
| ----------- | ------------------------------------ | ------- | -------------------------------------------------------------------------------------------------------------- |
| **CSMA/CD** | 搬送波感知多重アクセス／**衝突検出** | 有線LAN | データの**コリジョン（衝突）**を検知した場合、ジャム信号を送信してランダム時間待機後に再送する方式             |
| **CSMA/CA** | 搬送波感知多重アクセス／**衝突回避** | 無線LAN | **通信開始時にほかのデータを検出した場合はその通信が終了した後、ランダムな時間を待ってから通信を開始する方式** |

# 無線LANの識別とセキュリティ

| 用語                          | 特徴               | 内容                                                                                |
| ----------------------------- | ------------------ | ----------------------------------------------------------------------------------- |
| **ESSID**                     | ネットワーク識別名 | 複数のアクセスポイントをまたいで構成される無線LANネットワークの識別子               |
| **暗号化規格(WEP.WPA2etc.)**  | 通信データの保護   | **WEP**（脆弱性のため非推奨）、**WPA2**（従来標準）、**WPA3**（最新標準）などがある |
| **MACアドレスフィルタリング** | アクセス制限機能   | 端末固有の**MACアドレス**を登録し、許可された端末のみ接続させる機能                 |
| **ステルス機能**              | SSIDの隠蔽         | アクセスポイントが**ESSIDを周囲に通知（ブロードキャスト）しない**ようにする機能     |

# WANサービスとVPN（OSI参照モデルの対応レイヤー）

| 用語                  | 責任を持つ階層（OSI参照モデル） | 特徴                                                                                                     |
| --------------------- | ------------------------------- | -------------------------------------------------------------------------------------------------------- |
| **広域イーサネット**  | **第2層（データリンク層）**     | 通信事業者の独自網内でMACフレームを転送。拠点を同一LANのように接続でき、IP以外のプロトコルも透過可能     |
| **IP-VPN**            | **第3層（ネットワーク層）**     | 通信事業者の閉域IP網（MPLS等）を利用してIPパケット単位でルーティングを行う、高セキュリティな通信サービス |
| **インターネットVPN** | **第3層〜第4層以上**            | 公衆インターネット網上に暗号化トンネル（IPsecやSSL/TLS）を構築して通信を行う方式                         |

# モバイル通信とIoTネットワーク

| 用語                         | 特徴                                      | 内容                                                                                     |
| ---------------------------- | ----------------------------------------- | ---------------------------------------------------------------------------------------- |
| **モバイル通信サービス**     | 携帯電話網を利用した通信                  | キャリアが提供する無線通信インフラの総称                                                 |
| **LTE**                      | 4G相当の通信規格                          | 高速なデータ通信を実現する、現在のモバイル通信の基盤技術                                 |
| **5G**                       | 第5世代移動通信システム                   | 「超高速・大容量」「超低遅延」「多数同時接続」を特徴とする次世代通信規格                 |
| **MVNO**                     | 仮想移動体通信事業者                      | 自前の無線設備を持たず、大手キャリアから回線を借りて通信サービスを提供する事業者         |
| **キャリアアグリゲーション** | 通信の高速化技術                          | 複数の異なる**周波数帯（キャリア）を束ねて**、同時に通信を行うことで速度を向上させる技術 |
| **e-SIM**                    | 内蔵型SIM                                 | 物理カードを差し込まず、**端末内部のチップ**に通信プロファイルをダウンロードして利用する |
| **テザリング**               | インターネット共有機能                    | スマートフォン等を**モバイルルーター代わり**にし、PC等をネットに接続する機能             |
| **輻輳（ふくそう）**         | ネットワークの過負荷状態                  | 許容量を超えるトラフィックが集中し、遅延や通信切断などが発生する状態                     |
| **IoTネットワーク(LPWA)**    | Low Power Wide Area（低消費電力広域通信） | **低消費電力**かつ**広範囲**の通信が可能な、IoT機器（センサー等）に特化した無線通信技術  |
