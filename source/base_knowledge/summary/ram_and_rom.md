# RAM（Random Access Memory）

| 項目     | 内容                                              |
| -------- | ------------------------------------------------- |
| 正式名称 | Random Access Memory                              |
| 特徴     | CPUが処理中のデータやプログラムを一時的に格納する |
| 揮発性   | **あり**（電源を切るとデータが消える）            |
| 読み書き | **可能**                                          |

## RAMの種類

| 項目                     | DRAM                                                         | SRAM                                             |
| ------------------------ | ------------------------------------------------------------ | ------------------------------------------------ |
| 記憶方式                 | コンデンサに電荷を蓄える                                     | フリップフロップ回路で状態を保持                 |
| リフレッシュ             | **必要**                                                     | **不要**                                         |
| リフレッシュが必要な理由 | コンデンサの電荷が時間とともに漏れて、記憶内容が失われるため | フリップフロップが電源供給中は状態を保持するため |
| 集積度                   | **高い**                                                     | **低い**                                         |
| 速度                     | SRAMより遅い                                                 | **高速**                                         |
| 容量                     | 大容量化しやすい                                             | 大容量化しにくい                                 |
| 価格                     | 安価                                                         | 高価                                             |
| 主な用途                 | **メインメモリ**                                             | **キャッシュメモリ**                             |
| 覚え方                   | **大容量・高集積・リフレッシュ必要**                         | **高速・低集積・リフレッシュ不要**               |

# ROM

| 種類                 | 特徴                                                               | 書き込み             | 消去                                                                                                       |
| -------------------- | ------------------------------------------------------------------ | -------------------- | ---------------------------------------------------------------------------------------------------------- |
| **マスクROM**        | 製造時にデータを埋め込む。内容の変更を前提としない                 | **製造時に1回**      | **不可**                                                                                                   |
| **UV-EPROM**         | 紫外線によって記憶内容を消去できる                                 | 専用装置で書き込み   | **紫外線でチップ全体を消去**                                                                               |
| **EEPROM**           | 電気的に書き換え可能                                               | **電気的に書き込み** | **電気的に消去可能**。**チップ全体の消去だけでなく、バイト単位などで部分的に消去できる**                   |
| **フラッシュメモリ** | EEPROMを発展させたもの。大容量化しやすく、書き換え回数に制限がある | **電気的に書き込み** | **電気的に消去**。基本的に**ブロック単位でまとめて消去**する。方式によってはチップ全体を消去することもある |

## 覚え方

- **UV-EPROM** → 紫外線 → **全消去**
- **EEPROM** → 電気 → **部分消去可能**
- **フラッシュメモリ** → 電気 → **ブロック単位で消去**
