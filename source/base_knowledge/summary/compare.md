## 主記憶（RAM）の特徴

| 特徴                    | 内容                                                 |
| ----------------------- | ---------------------------------------------------- |
| **高速**                | CPUが処理するデータや命令を高速に読み書きできる      |
| **揮発性**              | 電源を切ると基本的にデータが消える                   |
| **一時記憶**            | 実行中のプログラムや処理中のデータを一時的に保持する |
| **比較的小容量**        | 補助記憶装置と比べて容量が小さい                     |
| **CPUから直接アクセス** | CPUが処理するためのデータや命令を保持する            |

## 補助記憶装置の特徴

| 特徴         | 内容                                           |
| ------------ | ---------------------------------------------- |
| **不揮発性** | 電源を切ってもデータを保持できる               |
| **大容量**   | 主記憶（RAM）より大容量のデータを保存できる    |
| **低速**     | 主記憶（RAM）と比べて読み書きが遅い            |
| **低コスト** | 1GBあたりの価格が主記憶（RAM）より安い         |
| **長期保存** | OS、アプリケーション、文書、画像などを保存する |
