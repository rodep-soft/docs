## 文字コード

| 文字コード        | 正式名称                                           | 特徴                                              |
| ----------------- | -------------------------------------------------- | ------------------------------------------------- |
| ASCIIコード       | American Standard Code for Information Interchange | 英数字や記号などを表現する7ビットの文字コード     |
| シフト\_JISコード | Shift Japanese Industrial Standards                | ASCIIコードに日本語の文字などを追加した文字コード |
| EUC               | Extended Unix Code                                 | Unix系システムなどで利用された文字コード          |
| Unicode           | Unicode                                            | 世界中の文字を統一的に扱うための文字コード体系    |
