# コンピュータの五大装置

コンピュータは、次の5つの装置から構成される。

1. **入力装置**
   - データや命令をコンピュータに入力する
   - 例：キーボード、マウス

2. **出力装置**
   - 処理結果を外部に出力する
   - 例：ディスプレイ、プリンタ

3. **記憶装置**
   - プログラムやデータを記憶する
   - 例：主記憶装置（RAM）、補助記憶装置（SSD、HDD）

4. **演算装置**
   - 算術演算や論理演算を行う
   - 例：CPU内部のALU

5. **制御装置**
   - 命令を解読し、各装置の動作を制御する

## CPU

**演算装置 + 制御装置 = CPU**

### 五大装置の関係

```text
             ┌────────────┐
             │ 制御装置   │
             └─────┬──────┘
                   │ 制御
                   ↓
入力装置 → 記憶装置 ↔ 演算装置 → 出力装置
             ↑          ↑
             └──────────┘
```
