# 独ステの概要　
1.動き方

各ホイールに「ステアリング角(方位)」と「駆動速度」の2自由度アクチュエータが独立して付いています。車輪の独立したステアリングと駆動は有名なロボット制御手法で、通常のステアリングがX方向速度とZ軸角速度の2自由度しか扱えないのに対し、X方向・Y方向の並進速度とZ軸角速度の合計3自由度を制御できます。
GitHub

具体的にできる動き:

前後・左右への並進(横移動、いわゆる「カニ歩き」)
斜め方向への並進
その場での回転(超信地旋回)
並進と回転を同時に行う複合動作(例:向きを変えずに斜めに進む)

差動駆動と比較すると、各ホイールの向きを常に制御できるためスリップが起きにくいという利点もあり、3輪以上の様々なレイアウトにも一般化しやすいという特徴があります。

運動学

上の図は、車体の並進速度 (vx, vy) と角速度 ω から、各ホイールの目標速度ベクトルがどう合成されるかを示しています。

逆運動学(車体速度→各ホイール指令)が基本になります。車体中心を基準にホイール i の位置を (xᵢ, yᵢ) とすると:

ホイールの速度ベクトル成分:
vx,ᵢ = vx − ω·yᵢ
vy,ᵢ = vy + ω·xᵢ
ホイール速度(スカラー): |vᵢ| = √(vx,ᵢ² + vy,ᵢ²)
ホイールのステアリング角: θᵢ = atan2(vy,ᵢ, vx,ᵢ)

図の右前輪の例のように、灰色(並進成分)+オレンジ(回転成分)をベクトル加算すると、緑色の最終的なホイール速度ベクトル(向きと大きさ)になります。他の3輪も中心からの距離・方向が異なるため、それぞれ違う角度に落ち着きます。

実装上の注意点もいくつかあります:

角度の最適化:目標角度への到達は、ホイールをそのまま回すか、180°反対に向けて速度を逆転させるかの2通りがあり、モジュールの回転量が少ない方を選ぶのが一般的です。
速度ゼロ付近の不定性:並進・回転指令がゼロに近いとき目標角度が数値的に不安定になるため、前回の角度を保持する処理が必要です。
