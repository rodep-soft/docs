# URDFについて

## URDFとは

URDFとはrosの環境でロボットの物理構造、外観、力学特性を定義するためのもので、標準フォーマットとしてXMLを使っています。
あくまでもロボットの設計図のようなものを設定するものがURDFというものである。

## 基本構造

URDFは基本的に剛体やある一つのパーツである**Link**とそれらをつなぐ関節となる**Joint**表現されています。
それらは、親リンクと子リンクに分けることができます。そして以下のルールが存在しています。

親リンク（parent）: 各リンクにつき必ず1つ（またはルートリンクのみ0個）
子リンク（child）: 1つのリンクに対して0個でも何個でも持てる

> [!NOTE]
> URDFは有向木を採用しているので枝分かれ（1つの胴体から左右の腕が生えるなど）は自由にできますが、合流（閉リンク機構・平行リンクなど）は記述できません。

## jointの使い分けについて

### 主要な4つの Joint

| Joint type       | 一般的な日本語表記・定訳                 | 特徴・制限                                                                 | 代表的な使用例                                                                    |
| :--------------- | :--------------------------------------- | :------------------------------------------------------------------------- | :-------------------------------------------------------------------------------- |
| **`revolute`**   | 回転関節 / 制限付き回転関節 / ヒンジ関節 | 1軸まわりの回転。<br>可動範囲（`<limit>` の上限・下限）の設定が必須。      | ロボットアームの肘や肩、首振り機構、グリッパーの指                                |
| **`continuous`** | 連続回転関節 / 無制限回転関節            | 1軸まわりの回転。<br>角度の上限・下限がなく360度以上何周でも回転し続ける。 | 車輪（タイヤ）、プロペラ、ローラー、連続回転ローラー                              |
| **`prismatic`**  | 直動関節 / スライド関節 / 並進関節       | 1軸方向への伸縮・直動。<br>移動距離の上限・下限（`<limit>`）の設定が必須。 | エレベーター昇降部、リニアスライダ、ピストン、直動型グリッパー                    |
| **`fixed`**      | 固定関節 / リジッド接合                  | 自由度0。<br>相対位置が完全に固定され、一切動かない接合。                  | カメラやLiDARの固定マウント部、台座と天板の締結部、基準座標系（`base_footprint`） |

---

### 参考：残りの2つ（滅多に使わないもの）

URDFの仕様上定義されている残りの2つがありますがこれはあまり使われません。

- **`floating`（浮遊関節 / 6自由度関節）**
  3軸の並進（X, Y, Z）と3軸の回転（Roll, Pitch, Yaw）を持つ自由度6の関節。空中を飛ぶドローンや水中艇などをモデル化する際に使われますが、ROSの標準ツールチェーンでは直接扱いにくいため、実務ではあまりURDF内には書きません。
- **`planar`（平面関節 / 3自由度平面関節）**
  特定の平面上を滑る関節（平面内の2軸並進 + 面直の1軸回転＝自由度3）。床面を滑る台車の表現などに用意されていますが、通常は車輪を `continuous` で組むため、こちらも滅多に使いません。
